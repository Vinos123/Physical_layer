## 3. ShareTechnote 学习路线

从用户给出的 [5G Handbook Index](https://www.sharetechnote.com/html/5G/Handbook_5G_Index.html)依次进入下列页面：

| 页面 | 建议带着什么问题读 |
|---|---|
| [PUSCH Channel Coding and Transmission Process](https://www.sharetechnote.com/html/5G/5G_PUSCH.html) | 每步输入输出是 bit 还是 complex symbol？ |
| [PUSCH DMRS](https://www.sharetechnote.com/html/5G/5G_PUSCH_DMRS.html) | 时间图案与频率图案分别由什么决定？ |
| [PUSCH Transmission Mode](https://www.sharetechnote.com/html/5G/5G_PUSCH_TxMode.html) | SRS、层数、TPMI 如何联系？ |
| [MCS/TBS/Code Rate](https://www.sharetechnote.com/html/5G/5G_MCS_TBS_CodeRate.html) | MCS 表索引如何得到 TB 大小？ |
| [Resource Allocation](https://www.sharetechnote.com/html/5G/5G_ResourceAllocation.html) | K0/K1/K2 分别用于什么方向？ |
| [Power Control](https://www.sharetechnote.com/html/5G/5G_PowerControl.html) | 开环项、路径损耗和闭环状态怎么叠加？ |

索引中的 Numerology、BWP、Resource Grid、LDPC、DCI、HARQ、UCI、SRS 等条目适合作为延伸阅读入口。

网页可能混合不同 Release 的表格或历史参数名。教程核对时特别处理了：PUSCH 接收端是 gNB；transform precoding 是 DFT 扩展；PUSCH 映射条款属于 6.3.1；Type A 的前置 DM-RS 位置不等于 PUSCH 起点限制。遇到冲突应回到本教程锁定版本的规范上下文。
