# C++ 原理例程与练习

官方完整 MATLAB 链路见 [MATLAB 官方例程导读](MATLAB官方例程导读.md)。本文件讲解原创 C++17 实验。它们不依赖 MATLAB、Python、FFT 库或前几部分的源代码，便于在 CLion 中单独调试。

## 1. 编译与运行

从当前项目根目录运行：

```bash
bash nr_pusch_tutorial/build_and_run.sh
```

脚本先编译并执行数值检查，再运行全部实验；输出写入教程目录的 `results/`。需要支持 C++17 的编译器；可用环境变量 `CXX` 指定。直接编译可避免当前路径含冒号时 Makefile 生成器的兼容问题。

只运行实验 2：

```bash
cd '/Users/Admin1/Desktop/4G:5G_physical_layer/nr_pusch_tutorial'
./build/nr_examples --example 2 --out results
```

开启地址与未定义行为检查：

```bash
SANITIZE=1 bash build_and_run.sh
```

CMake/CLion：将本目录作为独立项目打开，使用 Ninja 生成器；有 Ninja 的环境也可执行：

```bash
cmake -S . -B build-ninja -G Ninja
cmake --build build-ninja
ctest --test-dir build-ninja --output-on-failure
```

默认直接启动 `nr_examples` 会把结果写到当前工作目录的 `results`；脚本显式指定教程目录，CTest 指定构建目录。程序使用 `std::mt19937` 固定种子，但 C++ 标准库的正态分布实现可不同，因此跨平台随机实验不保证逐数值一致。

## 2. 源文件怎么读

| 文件 | 作用 |
|---|---|
| `examples/nr_core.hpp` | 核心接口与结构体 |
| `examples/nr_core.cpp` | 标准子过程及 DSP 教学函数 |

| `examples/nr_tests.cpp` | 独立参考、边界和长度检查 |

为帮助理解，FFT 和 Gold 都使用清晰的标量实现，不追求 SIMD 性能。长度、RE 和 bit 分开命名，主要计算使用 double。

## 3. 实验 1：调度资源编码

**问题：** 连续 RB 区间和符号区间怎样紧凑表示？

读 `riv()`、`sliv()`、`ex01()`。输出为 RIV=998、SLIV=53；同 SCS 下 grant slot 4、K2=2 对应 PUSCH slot 6。30 kHz 时隙长 0.5 ms，20 PRB 分配占宽 7.2 MHz。

**练习：** N=52、起点 5、长度 40，先判断应使用哪一个 RIV 分支。答案：长分配分支，RIV=722。

**限制：** 只编码数学区间；没有完整 DCI 位域解析、跨 numerology 时序、TDD/处理时延合法性检查。

## 4. 实验 2：RE → TBS → LDPC 尺寸

读 `resource_budget()`、`tbs_from_ninfo()`、`ldpc_sizes()`。主输出：

```text
NRE_TBS=2640  Ninfo=5053.125  TBS=4992  G=10560
TB_CRC=24  B=5016  BG=1  C=1  Kprime=5016
Zc=240  K=5280  filler=264  N=15840
```

输入 `dmrs_re` 与 `overhead` 均为**每 PRB、跨整个分配**的 RE 数，不是每符号数。`overhead!=0` 时函数不输出实际映射容量，用 −1 表示未确定，因为 xOverhead 不等于实际 RE 掩码。

小例得到 TBS=120；156 RE 上限例子得到 TBS=5888、G=12960。测试还检查 3824 两侧、R=0.25/0.67 两侧、分段、半整数舍入等。

**练习 A：** 将主例每 PRB 的 DM-RS 保留从 12 改为 24，其余不变。答案：N_RE=2400、G=9600、N_info=4593.75、TBS=4608。

**练习 B：** 对 A=9992、R=0.5 手算分段。答案：BG1，B=10016，C=2，每块 CB CRC=24，K'=5032；Zc=240，K=5280，每块 filler=248。

**限制：** 普通单时隙、单码字、至多 4 层的尺寸计算；不包含 LDPC 真实编码矩阵、译码、UCI 和 TBoMS。`ldpc_sizes` 要求合法 TBS 产生整数 K'，拒绝不满足此前提的任意输入。

## 5. 实验 3：Gold、DM-RS、QPSK 和资源掩码

读 `gold()`、`dmrs_cp()`、`qpsk()`、`ex03()`。调度范围为符号 2–13、PRB 0–19，DM-RS 在符号 2/11 的偶数子载波。CSV 中 0=未分配，1=数据，2=DM-RS。

发送流程：生成随机比特 → 与 Gold 序列异或 → QPSK → 放入数据 RE；接收流程按相同坐标提取 → 判决 → 解扰。预期 2640 个数据 RE、240 个 DM-RS RE、5280 个 QPSK 输入 bit、0 个回环错误。

注意：本实验是 QPSK 映射实验；主例的 16QAM 容量为 10560 bit。没有先生成 4992 bit 的 TB 再做 LDPC，因此不能把这里的“0 错误”当成完整 PUSCH 解码通过。

`results/dmrs.csv` 保存 symbol、subcarrier、实部和虚部，供 MATLAB 对拍。Gold 测试用独立整数移位寄存器实现作参照；这比发送、接收都调用同一个函数再检查自洽更有价值。

**练习：** 只把接收端数据加扰 ID 改成另一个值，观察错误率；再只改 DM-RS ID。前者直接破坏数据恢复，后者在当前映射回环中不会改变数据判决，因为此例尚未使用导频估计信道。这可帮助识别“写了导频，但接收机没有用到它”的伪验证。

**限制：** 基本 CP-OFDM、normal CP、一个端口、CRB 起点 0、无跳频；不含 UCI 特殊占位、增强 DM-RS、变换预编码 DM-RS 或多端口 OCC。

## 6. 实验 4：CP-OFDM 与 DFT-s-OFDM

读 `dft()`、`fft()`、`papr_db()`、`ex04()`。256 点 IFFT、连续 72 子载波、固定 CP=32、400 次试验。两种模式共享每次的原始 QPSK 数据，DFT-s-OFDM 多一个 72 点 DFT，接收时再做相应 IDFT。

程序用 1024 点 IFFT 对相同频谱过采样，统计**不含 CP 的有用符号** PAPR。均值是逐符号 PAPR(dB) 的算术平均，p99 使用 nearest-rank 第 396 个值，而不是插值分位数。

本机结果：CP-OFDM 平均约 7.57 dB，DFT-s-OFDM 约 5.41 dB；回环误差分别约 7.1e−15、6.3e−14。测试另用直接 DFT 检查 radix-2 FFT、逆变换和能量守恒。

**练习：** 改变占用子载波数，但保持小于 NFFT；比较 PAPR 分布。不要仅挑一条波形证明普遍结论。

**限制：** 固定 CP，无真实 DM-RS/PT-RS、频偏、功放模型和 NR 符号相位补偿。展示波形原理，不输出标准一致性波形。

## 7. 实验 5：DM-RS 支持的 LS 估计与均衡

读 `ex05()`。信道固定为 H=0.7+0.4j，使用 120 个 DM-RS 样本估计一个复数 H，再对 100000 个 QPSK 符号做 SISO ZF。每个 SNR 点重新产生噪声。

噪声定义：发射数据 Es=1，总复噪声功率 N0=10^(−EsN0_dB/10)，I/Q 各为 N0/2。由于 |H|²=0.65，接收符号 SNR 比输入 Es/N0 低约 1.87 dB。这里没有编码率、CP 或导频能量折算，所以横轴不是总发送能量口径 Eb/N0。

| Es/N0 | 本机 BER | 本机 EVM |
|---:|---:|---:|
| 0 dB | 0.211605 | 124.60% |
| 5 dB | 0.075925 | 70.80% |
| 10 dB | 0.005425 | 39.45% |
| 20 dB | 0 | 12.60% |

有限样本中 0 个错误不表示理论 BER 为零。无错误观测的粗略 95% 上界可用 3/N 估计，此处 N=200000 bit，约 1.5e−5；这只是独立错误近似下的统计辅助。

**练习：** 将接收机 Hhat 暂时替换为真实 H，观察估计损失；再把每个导频位置对应的 H 改成不同值，说明全局平均为什么失效。

**限制：** 静态平坦 SISO、独立复高斯噪声、频域符号模型；没有完整 OFDM 接收、多径、时间插值或 MMSE/MIMO。不同 SNR 点的单次估计误差不保证严格单调。

## 8. 实验 6：软信息合并

读 `ex06()`。BPSK x∈{−1,+1}，每次实噪声方差为 0.5，LLR=2y/σ²。分别判决第一轮与两轮 LLR 和。本机 BER 从 0.07913 降至 0.02263。

作为独立原理参照，第一轮理论 BER 为 Q(1/sqrt(0.5))≈0.07865；两轮合并为 Q(2)≈0.02275，仿真接近这些值。

**练习：** 第二轮噪声方差改为 2。先仍使用正确的每轮方差生成 LLR，再故意错误地给两轮相同权重，比较性能。

**限制：** 同一符号的重复观测，非 NR HARQ 实现。没有 RV、LDPC、CRC、进程管理；发送两轮消耗两倍能量和相应资源。

## 9. 实验 7：功率饱和与测量口径

读 `pusch_power()`、`ex07()`。20/40/80/160 PRB 分别请求约 16.02/19.03/22.04/25.05 dBm；最后一个被 PCMAX=23 dBm 限制。

输出 `relative_PSD_dB` 为 `actual - 10log10(2^μ*M_RB)` 在本例零基线下的相对变化，用于看功率饱和造成的下降。它不是 dBm/Hz 的绝对功率谱密度，不能拿去与频谱仪读数直接比。

附带两个测量算例：RSRQ≈−13.01 dB；−80 与 −100 dBm 在线性功率域平均后约 −82.97 dBm。

**练习：** 固定 PRB 数，提高 PL，画出发射功率何时开始饱和。若 α=0.8，每增加 10 dB 路损，未封顶阶段请求功率提高 8 dB；封顶后不能继续按比例补偿。

**限制：** 单载波、单功控状态、静态 PL；不含多载波并发功率分配、TPC 累积状态机和真实 RSRP/RSSI 测量掩码。

## 10. 从教学程序走向标准实现

先用上述小实验理解口径，再运行官方 MATLAB 完整链路。随后若要实现 C++ 端到端 PUSCH，建议顺序是：独立 CRC/LDPC 向量 → 速率匹配与 RV → 单层无 UCI CP-OFDM → DM-RS 信道估计 → HARQ → UCI → 多层/跳频/增强特性。每阶段都用独立标准实现对拍，避免只有自回环。
