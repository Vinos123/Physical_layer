# 核心术语、公式与易错点

配合[教程正文](教程正文.md)使用。术语按数据流分组；标准条款与版本见[索引](参考资料与标准索引.md)。

## 1. 时频资源与信道

| 术语 | 英文 | 中文解释及辨析 |
|---|---|---|
| UE | User Equipment | 用户设备；PUSCH 的发送方 |
| gNB | next generation Node B | NR 基站；PUSCH 的接收方 |
| NR | New Radio | 5G 无线接入技术 |
| UL / DL | Uplink / Downlink | 上行/下行，以 UE 到基站为上行 |
| Numerology / μ | Numerology | 子载波间隔及相关时域结构的参数化配置 |
| SCS | Subcarrier Spacing | 子载波间隔；不是采样率 |
| CP | Cyclic Prefix | 循环前缀；用于缓解多径下的符号间干扰并支持频域处理 |
| Slot / Symbol | Slot / OFDM Symbol | 时隙/OFDM 符号；不要与调制星座符号混称 |
| RE | Resource Element | 一个子载波和一个 OFDM 符号构成的时频单元 |
| RB / PRB | Resource Block / Physical RB | 频域 12 个连续子载波；本地 PRB 编号通常属于 BWP |
| CRB | Common Resource Block | 公共资源块坐标，与 Point A 关联 |
| VRB | Virtual Resource Block | 分配过程中的虚拟资源块，须按规则映射为 PRB |
| Point A | Point A | NR 公共资源块网格的频率参考 |
| BWP | Bandwidth Part | 带宽部分，带有起点、大小及 numerology 等配置 |
| FDD / TDD | Frequency / Time Division Duplex | 频分/时分双工；TDD 需检查上下行符号可用性 |
| UL-SCH | Uplink Shared Channel | 运输信道，描述数据传送；不是一张 RE 网格 |
| PUSCH | Physical Uplink Shared Channel | 上行共享物理信道，可承载 UL-SCH 及复用 UCI |
| PUCCH | Physical Uplink Control Channel | 上行控制物理信道 |
| PDCCH | Physical Downlink Control Channel | 下行控制物理信道，承载 DCI |
| PDSCH | Physical Downlink Shared Channel | 下行共享物理信道 |
| PRACH | Physical Random Access Channel | 物理随机接入信道 |
| SSB | SS/PBCH Block | 同步信号与 PBCH 组成的块，用于初始接入等 |

这些对象的标准定义与结构入口为 [38.211 §4、§6、§7](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/18.05.00_60/ts_138211v180500p.pdf)。

## 2. 调度、编码与 HARQ

| 术语 | 英文 | 中文解释及辨析 |
|---|---|---|
| RRC | Radio Resource Control | 无线资源控制；提供长期/半静态配置背景 |
| DCI | Downlink Control Information | 下行控制信息；上行 grant 也属于 DCI |
| Grant | Uplink Grant | 授予一次或一组上行传输资源的调度信息 |
| CG | Configured Grant | 配置授权，减少逐次动态指示需求 |
| RNTI | Radio Network Temporary Identifier | 无线网络临时标识；用于寻址及相关物理层初始化 |
| TDRA / FDRA | Time/Frequency Domain Resource Allocation | 时域/频域资源分配 |
| K2 | PUSCH scheduling offset | 上行调度到 PUSCH 的时间关系参数 |
| K0 / K1 | Scheduling / feedback timing offsets | 常见于下行调度及 HARQ-ACK 时序，不可与 K2 互换 |
| SLIV | Start and Length Indicator Value | 起始符号与长度的紧凑编码 |
| RIV | Resource Indication Value | 资源区间的紧凑编码，常用于连续 RB 分配 |
| MCS | Modulation and Coding Scheme | 调制编码方案；索引必须结合所用表解释 |
| Qm | Modulation order in bits | 每个调制符号的比特数，如 QPSK=2、16QAM=4 |
| R | Target code rate | MCS 给出的目标码率，不保证等于最终 A/G |
| TB / TBS | Transport Block / TB Size | 运输块/运输块大小；本教程 A 不含 TB CRC |
| CB / CBG | Code Block / Code Block Group | 码块/码块组；不要把 CB 当独立用户数据包 |
| CRC | Cyclic Redundancy Check | 循环冗余校验，主要用于检错 |
| LDPC | Low Density Parity Check | 低密度奇偶校验码，数据纠错编码 |
| BG | Base Graph | NR QC-LDPC 的基图类型 |
| Zc | Lifting size | 基图展开尺寸，必须取合法离散值 |
| Filler | Filler bits | 适配编码块尺寸的填充位置，不是实际用户比特 |
| Rate matching | Rate matching | 使母码输出适应本次容量，包括选择/重复/交织等 |
| UCI | Uplink Control Information | 上行控制信息，含 HARQ-ACK、CSI 等；SR 常见于 PUCCH |
| CSI | Channel State Information | 信道状态信息，不能简单等同瞬时 SNR |
| HARQ | Hybrid Automatic Repeat Request | 纠错编码与重传结合的机制 |
| NDI | New Data Indicator | 新数据指示，与 HARQ 进程上下文共同解释 |
| RV | Redundancy Version | 冗余版本，影响母码比特的选择 |
| LLR | Log Likelihood Ratio | 软比特可信度，符号约定必须统一 |
| BLER / BER | Block / Bit Error Rate | 块错误率/比特错误率；粒度不同 |

编码相关规则见 [38.212 §5、§6.2、§6.3](https://www.etsi.org/deliver/etsi_ts/138200_138299/138212/18.05.00_60/ts_138212v180500p.pdf)；数据调度过程见 [38.214 §6.1](https://www.etsi.org/deliver/etsi_ts/138200_138299/138214/18.05.00_60/ts_138214v180500p.pdf)。

## 3. 参考信号、空间处理与测量

| 术语 | 英文 | 中文解释及辨析 |
|---|---|---|
| DM-RS | Demodulation Reference Signal | 解调参考信号；估计与数据一致的等效信道 |
| PT-RS | Phase Tracking Reference Signal | 相位跟踪参考信号；主要用于公共相位误差 |
| SRS | Sounding Reference Signal | 探测参考信号；支持上行信道探测与发送选择 |
| CDM | Code Division Multiplexing | 码分复用；多个端口可共享物理 RE |
| OCC | Orthogonal Cover Code | 正交覆盖码，帮助分离复用端口 |
| Layer / Rank | Layer / Rank | 层/秩，描述并行流及信道空间维数的相关概念 |
| Antenna port | Antenna port | 由参考信号与信道关系定义的逻辑端口，不是天线插口编号 |
| TPMI | Transmitted Precoding Matrix Indicator | 发送预编码矩阵指示 |
| SRI | SRS Resource Indicator | SRS 资源指示，参与上行传输参数选择 |
| CP-OFDM | Cyclic Prefix OFDM | 循环前缀正交频分复用 |
| DFT-s-OFDM | DFT-spread OFDM | DFT 扩展 OFDM；增加符号域 DFT |
| PAPR | Peak-to-Average Power Ratio | 峰均功率比，与功放回退和效率相关 |
| LS / MMSE / ZF | Least Squares / Minimum Mean Square Error / Zero Forcing | 最小二乘/最小均方误差/迫零 |
| CFO / ICI / CPE | Carrier Frequency Offset / Intercarrier Interference / Common Phase Error | 载波频偏/载波间干扰/公共相位误差 |
| TA | Timing Advance | 定时提前，补偿到达时间偏差 |
| TPC | Transmit Power Control | 发射功率控制 |
| PHR | Power Headroom Report | 功率余量报告；不能任意等同 PCMAX 减实测功率 |
| PL / α | Path Loss / compensation factor | 路径损耗/分数补偿系数 |
| RSRP | Reference Signal Received Power | 参考信号接收功率；先说明 SS/CSI/SRS 等类型 |
| RSSI | Received Signal Strength Indicator | 接收信号强度；包含的信号/干扰/噪声由测量定义决定 |
| RSRQ | Reference Signal Received Quality | 参考信号接收质量 |
| SINR | Signal to Interference plus Noise Ratio | 信号与干扰加噪声功率之比；需说明测量位置和集合 |
| EVM | Error Vector Magnitude | 误差矢量幅度；不同测量条件不能直接比较 |
| dB / dBm | Decibel / dB relative to 1 mW | dB 是比值，dBm 是相对 1 mW 的功率 |
| Goodput | Successfully delivered new payload rate | 成功交付新数据的速率，排除重复交付计数 |

参考信号与发送方式入口见 [38.214 §6.1.1、§6.2](https://www.etsi.org/deliver/etsi_ts/138200_138299/138214/18.05.00_60/ts_138214v180500p.pdf)，功控见 [38.213 §7](https://www.etsi.org/deliver/etsi_ts/138200_138299/138213/18.05.00_60/ts_138213v180500p.pdf)，测量见 [38.215 §5](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)。

## 4. 主实例变量账本

| 变量 | 数值 | 单位与口径 |
|---|---:|---|
| N_PRB | 20 | RB |
| L | 12 | OFDM 符号 |
| N_DMRS | 12 | 每 PRB、跨整个分配的保留 RE 数 |
| N_RE,TBS | 2640 | TBS 计算口径 RE |
| N_RE,actual | 2640 | 实际数据映射 RE，本例与前者相等 |
| Qm / ν | 4 / 1 | 每符号 bit 数/层数 |
| R | 490/1024 | 目标码率，无量纲 |
| N_info | 5053.125 | 量化前中间信息比特估计 |
| A=TBS | 4992 | bit，不含 TB CRC |
| B | 5016 | bit，包含 TB CRC |
| C / K' | 1 / 5016 | CB 数/每 CB 有效输入尺寸 |
| Zc / K | 240 / 5280 | lifting size/LDPC 系统部分尺寸 |
| F / N | 264 / 15840 | 每块 filler/去掉前 2Zc 后的编码输出长度 |
| G | 10560 | 本次无 UCI 的速率匹配输出 bit 数 |

**长度检查顺序：** A → B → C、K' → Zc、K、F → N → G → G/Qm 个调制符号 → 数据 RE。不要依赖变量名字隐含单位。

## 5. 公式速查

| 公式 | 条件 |
|---|---|
| Δf=15·2^μ kHz，Tslot=1/2^μ ms | 本教程普通 CP |
| Fs=NFFT·Δf | FFT 离散时间实现，注意 Δf 用 Hz |
| N_RE,TBS=min(156,12L−N_DMRS−N_oh)·N_PRB | 普通单时隙 TBS 计算分支 |
| N_info=N_RE,TBS·Qm·R·ν | 单码字分支；扩展特性另查条款 |
| G=N_RE,actual·Qm·ν | 无 UCI 等额外占用时 |
| Hhat=Yp/Xp | 单端口、已知非零导频 |
| s_hat=Y/Hhat | SISO ZF，深衰落易放大噪声 |
| Ltotal=L1+L2 | 对齐到同一比特且独立观测，噪声尺度正确 |
| EVM=sqrt(Σ|s_hat−s|²/Σ|s|²) | 本教程的数值实验口径 |
| PAPR=max|x|²/mean|x|² | 说明是否过采样、是否包含 CP |
| P[dBm]=10log10(P[mW]) | 功率必须大于零 |
| RSRQ=N·RSRP/RSSI | 线性域，测量集合须匹配 |

## 6. 十个易混概念

1. **运输信道与物理信道：** UL-SCH 描述数据运输，PUSCH 描述无线承载。
2. **TBS 与 G：** 前者是数据块尺寸，后者是本次编码比特容量。
3. **目标码率与有效码率：** 必须说明是否含 CRC、filler 与 UCI。
4. **Type A/B 与 type 1/2：** 一个主要关乎时间参考，一个关乎 DM-RS 频域结构。
5. **端口与天线：** 一个是逻辑信道关系，一个是硬件。
6. **DFT 预编码与空间预编码：** 一个扩展符号，一个混合空间流。
7. **SRS 与 DM-RS：** 探测资源不自动等于本次数据的解调参考。
8. **下行 HARQ-ACK 与上行 HARQ：** PUSCH 携带的 ACK 与该 PUSCH 自身接收结果不是一回事。
9. **K2 与 TA：** 一个处理调度时间，一个处理传播到达时间。
10. **标准测量与接收机内部指标：** 相同名称下也必须核对定义与归一化。
